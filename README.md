# PNZH modpack

Список модов для лаунчера сервера «Майнкрафтская PNZH». Лаунчер скачивает `modpack.json` при каждом нажатии «Играть» и приводит папку `mods` игрока к этому списку.

- `minecraft`, `loader` — версия игры и Fabric.
- `mods` — моды: ссылка на Modrinth, имя файла, sha512.
- `shaderpacks` — шейдеры (по умолчанию выключены в игре).

Сами моды здесь не хранятся: они скачиваются напрямую с Modrinth.
